# Scrapper Web App

Proyecto desarrollado con Flask + Bootstrap.

## Funciones:
- Scraping de páginas web
- Indexación de documentos PDF
- Búsqueda con similitud (Levenshtein)
- Dashboard con estadísticas

## Tecnologías:
- Python
- Flask
- Bootstrap
- SQLite

## Cómo correr:
```bash
pip install -r requirements.txt
python app.py
